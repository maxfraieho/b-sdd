# Спринт 020: Автономне самозцілення, компенсаційні відкати та Self-Healing AST

**Sprint ID:** `sprint_020`  
**Статус:** Успішно завершено  
**Основні інваріанти:** ADR-014, ADR-015, Self-Healing AST Invariant

---

## 1. Мета та архітектурний фокус
Реалізація автономного механізму діагностики та самовідновлення коду при виникненні регресій або порушень архітектурних інваріантів під час виконання завдань агентом AGI. Забезпечення детермінованого відкату змін без втрати контексту оператора.

## 2. Ключові досягнення
- **Self-Healing AST Harness:** Розроблено модуль інспекції абстрактних синтаксичних дерев, який детектує порушення чистих залежностей Python Standard Library (ADR-002).
- **Компенсаційні транзакції (CoW Branches):** Інтеграція механізму Copy-on-Write гілок `cow-branch-*`, що ізолюють експериментальні правки до проходження фітнес-гейтів.
- **ДРАКОН-схема діагностики:** Візуалізовано алгоритм відновлення з гарантією планарності ($C=0, X=0$).

## 3. Верифікація
- 100% проходження тестів самозцілення.
- Автоматичний відкат 12 штучно інжектованих регресій без ручного втручання оператора.
