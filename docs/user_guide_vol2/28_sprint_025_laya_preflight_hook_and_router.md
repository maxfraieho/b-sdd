# Спринт 025: Пре-флайт хук Laya в супервайзері та скіл маршрутизації рішень

**Sprint ID:** `sprint_025`  
**Статус:** Успішно завершено  
**Основні інваріанти:** ADR-002, ADR-003, Pre-Flight Sub-40ms Invariant

---

## 1. Мета та архітектурний фокус
Інтеграція класифікатора Laya безпосередньо у вхідний пайплайн супервайзера `bsdd_supervisor.py`. Створення стандартизованого скіла `laya-decision-router` для вибору оптимальних процедурних навичок ядра (з 48 Golden Core) перед запуском LLM.

## 2. Ключові досягнення
- **Pre-Flight Hook у супервайзері:** При отриманні POST `/dispatch` супервайзер здійснює швидкий запит до демона Laya та інжектує контекстну капсулу `[LAYA DECISION CONTEXT: Domain, Confidence, Recommended Skills]` у системний промпт планувальника.
- **Статичний фолбек-механізм:** При недоступності або засинанні смартфона Podroid супервайзер миттєво перемикається на детерміновану евристику без затримок.
- **Скіл `laya-decision-router`:** Створено повноцінний скіл у `~/.agents/skills/laya-decision-router` із підтримкою тестування та валідації.
