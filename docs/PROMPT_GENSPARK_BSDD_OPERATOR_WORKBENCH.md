# Genspark Master Prompt: B-SDD Human-in-the-Loop Operator Workbench
## Інженерний кокпіт мультиагентної оркестрації, бітемпоральних ADR та алгоритмічних ДРАКОН-схем (SaaS Edition)

---

## 1. СИСТЕМНЕ ПОЗИЦІОНУВАННЯ ТА АРХІТЕКТУРНИЙ БАЗИС

**Назва продукту:** B-SDD Operator Workbench (Engineering Cockpit)  
**Цільове призначення:** Професійний інженерний веб-кокпіт оператора (Human-in-the-Loop) для детермінованої оркестрації агентних циклів розробки, візуального проектування алгоритмів на мові ДРАКОН (Drakon-as-Spec), бітемпоральної навігації за архітектурними рішеннями (ADR) та управління мультисесійними ланцюгами спринтів без дрейфу контексту.  
**Технологічний стек фронтенду:** React 18/19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Radix UI / shadcn/ui.  
**Стек бекенду та суверенної інфраструктури:**
- **Control Plane:** Appwrite BaaS (Auth, Teams RBAC, Realtime WebSockets, Subscriptions).
- **Sovereign Execution VPC:**
  - `Utopia DB` на хості `.251:9922` (PostgreSQL 16, pgvector, Tantivy, бітемпоральні виміри $T_v$ та $T_t$).
  - `LLM Gateway` на хості `.184:18880 / 8082` (8 слотів моделей: `agent-proxy`, `coding-proxy`, `reasoning-proxy`).
  - `GitNexus AST Engine` на хості `.184:4747` (топологічний граф викликів та меж компонентів).
**Платформа розгортання:** Cloudflare Pages (статичний бандл `dist/` з підтримкою SPA-роутингу через `_redirects`).

## 2. АВТОМАТ СТАНІВ HUMAN-IN-THE-LOOP (7 ФАЗ РОЗРОБКИ)

Інтерфейс візуалізує та керує 7 дискретними фазами детермінованого циклу:

| Фаза | Назва фази | Семантика та задачі | Валідаційний бар'єр | Рівень HITL |
| :--- | :--- | :--- | :--- | :--- |
| $\Phi_1$ | **Intent Framing (ADR)** | Формулювання архітектурного наміру у вигляді MADR в Utopia DB | Відсутність конфліктів із діючими ADR | **100% Оператор** (Агент фасилітує) |
| $\Phi_2$ | **Algorithmic Spec (DRAKON)** | Проектування графа алгоритму (шампур, альтернативи, силует) | Топологічна валідність (планарність, без перетинів) | **50% Нагляд** (Специфікатор-агент) |
| $\Phi_3$ | **Pre-Flight Compilation** | Статична перевірка правил `.context/active_rules.md` (<20 мс, <500 слів) | 0 застарілих ADR, дотримання токен-бюджету | **0% Автомат** (Блокує при помилці) |
| $\Phi_4$ | **Phased Code Execution** | Синтез коду суворо всередині ікон «Дія» через локальний шлюз `.184` | Топологія графа заблокована від змін | **0% Автомат** (Кодер-агент) |
| $\Phi_5$ | **Automated Fitness Gates** | Прогін архітектурних тестів `pytest`, перевірка AST-ізоляції | 100% проходження тестів, ліміти пам'яті | **0% Автомат** (Верифікатор-агент) |
| $\Phi_6$ | **Human Review Gate** | Фінальна інспекція оператором коду, diff специфікацій, звітів | **Синхронний підпис крипто-сертифіката схвалення** | **100% Головний архітектор** |
| $\Phi_7$ | **Distillation & Handoff** | Потоковий витяг уроків, очищення шуму, генерація `.context/next_sprint.md` | Цілісність графа Utopia DB, готовність команди | **20% Нагляд** (Агент дистиляції) |

### Протокол відхилення та ветвлення (Reject & Branch Protocol):
Якщо на фазі $\Phi_6$ оператор відхиляє результат (кнопка `[ ❌ Reject & Branch ]`):
1. Стан фіксується у Utopia DB на момент $T_{reject}$ через copy-on-write знімок.
2. Відхилена гілка закривається по дійсному часу ($V_{end} = T_{current}$).
3. Для нової спроби створюється чистий контекст: шум і помилковий код минулої сесії **не передаються**.
4. Замість цього передається специфікація ДРАКОН та мінімальний негативний вектор інваріантів:
   $$\Delta C = \{ \text{Invariant}_k \mid \text{Violation}(\text{Invariant}_k, \text{Run}_{prev}) = \text{True} \}$$

## 4. ДЕТАЛІЗАЦІЯ КЛЮЧОВИХ КОМПОНЕНТІВ

### 4.1 Спринт-Кокпіт (Dev Cycle Command Center)
- **Степпер фаз $\Phi_1 - \Phi_7$:**
  - Кожен крок має візуальну колірну індикацію (сірий = очікування, синій пульсуючий = виконання, янтарний = компіляція, фіолетовий = шлюз оператора, смарагдовий = підтверджено, рожевий = відхилено/ветвлення).
- **Плашка блокуючого шлюзу людини ($\Phi_6$ Review Gate):**
  - Показує підсумковий звіт фітнес-функцій (наприклад, `70/70 tests passed in 149.91s`, `AST Isolation: 100%`).
  - Відображає кнопковий блок оператора:
    - `[ 🛡️ Затвердити та підписати сертифікат (Approve & Merge) ]`
    - `[ ❌ Відхилити та розгалузити (Reject & Branch) ]` (відкриває модальне вікно вибору глибини відкату та формулювання негативного інваріанту $\Delta C$).
- **Консоль естафети (Sprint Handoff Console):**
  - Віджет попереднього перегляду файлів `.context/next_sprint.md` та `sprint_handoff.json`.
  - Поле з готовою командою наступного спринту:
    `./run_b_sdd.sh "Виконати Milestone 2: Реєстр інструментів..."`
  - Кнопка швидкого копіювання `[ 📋 Copy Launch Command ]`.

### 4.2 Студія ДРАКОН (Drakon-as-Spec Canvas powered by DrakonWidget)
- **Канонічний рушій рендерингу:** Полотно базується на перевіреному відкритому рушії [stepan-mitkin/drakonwidget](https://github.com/stepan-mitkin/drakonwidget) (`/libs/drakonwidget.js`). Заборонено створювати ad-hoc SVG-малювалку; замість цього drakonwidget обгортається в React-компонент через адаптер.
- **Дотримання стандарту ДРАКОН:**
  - **Шампур (The Skewer):** суворо вертикальна лінія зверху вниз по лівому краю.
  - **Вузли-ікони:** «Заголовок» (Headline), «Дія» (Action), «Питання» (Question), «Силуетний перехід» (Silhouette Route), «Кінець» (End).
  - Відхилення та обробка помилок — тільки праворуч. Перетини ліній заборонені.
- **Інспектор вузла:** при кліку на вузол показує:
  - Прив'язаний інваріант ADR (наприклад, `ADR-0024-INV-02: Cloudflare WAF Bypass`).
  - Сутність Utopia DB (`ent_groq_stt_router`).
  - Згенерований блок коду Python.

### 4.3 Бітемпоральний слайдер ADR (Bitemporal ADR Timeline Slider)
- Два інтерактивні бегунки координатної сітки:
  - **Бігунок $T_v$ (Valid Time):** зміна положення динамічно змінює граф ADR. Якщо обрано дату, коли ADR-008 ще був чинним, він відображається зеленим. При переміщенні вправо ADR-008 перекреслюється і стає сірим, а активним підсвічується ADR-013.
  - **Бігунок $T_t$ (Transaction Time):** відновлює фізичний знімок бази даних Utopia на вказану секунду історії.
- Двопанельний переглядач ADR (список зліва + повнотекстовий Markdown справа).

### 4.4 Панель суверенного ШІ-копілота (Sovereign LLM Copilot Panel)
- Прямий стрімінг через Server-Sent Events (SSE) до суверенного проксі `http://192.168.3.184:18880/v1`.
- **Селектор пулу 8 слотів:**
  - `agent-proxy` (Llama-3.2 11B Vision / швидкий роутинг ~0.6с)
  - `coding-proxy` (Qwen 2.5 Coder 32B / точний код)
  - `reasoning-proxy` (DeepSeek R1 / важка системна логіка)
- **Токен-спідометр:** лічильник слів та токенів поточного контексту проти ліміту 500 слів для активних правил B-SDD.
- **Кнопки швидкого прикріплення контексту:** `[ + Активний ADR ]`, `[ + Поточна схема ДРАКОН ]`, `[ + Звіт Pytest ]`.

## 5. МОДЕЛЬ SAAS ТА ТАРИФІКАЦІЯ ЗА ЦИКЛАМИ (APPWRITE BAAS)

Замість застарілої моделі оплати за токени впроваджується метрика бізнес-результату: **B-SDD Verified Execution Cycle** (повний верифікований цикл розробки):
- **Community Tier ($0):** Self-hosted на власних серверах, необмежені цикли на власній Utopia DB та LLM Gateway.
- **Pro Team Tier ($499/міс):** До 15 користувачів у команді Appwrite, 500 підтверджених циклів на місяць, хмарний бекап бітемпорального графа.
- **Enterprise Sovereign ($3,500+/міс):** Необмежені цикли, виділений раннер у контурі замовника, довічний WORM-аудит.
