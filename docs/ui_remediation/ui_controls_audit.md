## Зона B: DRAKON Studio (Канвас та Панель Інструментів)
Код: [`b-sdd-ui/src/components/DrakonStudio/DrakonToolbar.tsx`](file:///home/vokov/projects/b-sdd/b-sdd-ui/src/components/DrakonStudio/DrakonToolbar.tsx)

1. **Тулбар ДРАКОН:**
   - Назва поточної схеми.
   - Перемикач режимів: `widget` (інтерактивний канвас), `flow` (SVG потік), `json` (сире IR-дерево).
   - Масштабування (`ZoomIn`, `ZoomOut`, `Reset / Home`).
   - Кнопка «Псевдокод» (`Code2`): експорт алгоритму в текстовий псевдокод.
   - Кнопка «Експорт JSON» (`Download`).
   - Кнопка «Зберегти схему» (`Save`): відправляє схему на бекенд `POST /api/drakon/save`.
   - Стан: **Живий**.

2. **Палітра Фігур (`DrakonIconPalette`):**
   - Містить понад 20 фігур (Дія, Питання, Початок, Кінець, Пауза, Паралельний процес, Таймер, Вставка тощо).
   - Питання аудиту: *Чи не перевантажує вона канвас? За стандартом B-SDD 95% алгоритмів використовують лише 4-5 ключових фігур.*
